### Financial Advisor Workflow

This workflow prompts a user for information and provides a brief financial recommendation based on the user inputs.

#### Create a Workflow

- Click on **Create Agent**
- Under the **Toolset** section, click on the **Add tool** button.

  ![Add Tool](./flow_builder_imgs/i1.png)

- Click on **Create an agentic workflow**.

  ![Import](./flow_builder_imgs/i2.png)

- Click on the **green play button**.

  ![Import from file](./flow_builder_imgs/i3.png)

- Click on the **edit button**.
  
  ![Upload spec file](./flow_builder_imgs/i4.png)

- Click **Add**.

  ![Upload spec file](./flow_builder_imgs/i4a.png)

- Select **Decimal**.

  ![Upload spec file](./flow_builder_imgs/i4b.png)

- Click on **Add +** and then select **String**.
    - In the Name field write:
    ```
    Input
    ```
    - In the Description field write:
    ```
    User requesting financial planning/analysis
    ```
    ![Upload spec file](./flow_builder_imgs/i5.png)
- Click on **Add**

    ![Upload spec file](./flow_builder_imgs/i5.png)

- Click on the **grey square button**.

  ![Upload spec file](./flow_builder_imgs/i6.png)

- Click on **Add +** and then select **Decimal**.

- In the Name field write:
    ```
    Output
    ```
    - In the Description field write:
    ```
    Financial planning/analysis generated by tool
    ```

    ![Upload spec file](./flow_builder_imgs/i7.png)

- Click on **Add/Save**

    ![Upload spec file](./flow_builder_imgs/i8.png)

- Hover over the arrow between inputs and outputs, select the **Plus** button

  ![Select Operations](./flow_builder_imgs/i9.png)

- Select **User activity**

  ![Select Operations](./flow_builder_imgs/i10.png)

- Select the **Form** option

  ![Select Operations](./flow_builder_imgs/i11.png)

- Select **Add field**

  ![Select Operations](./flow_builder_imgs/i12.png)

- Select **Number**
  
  ![Select Operations](./flow_builder_imgs/i13.png)

- For the Label, enter:
    ```
    Available Account Balance
    ```
- Set **Required** to **On** and **Input Type** to **Decimal**

    ![Select Operations](./flow_builder_imgs/i14.png)

- Select the **Plus** and then **Number**

    ![Select Operations](./flow_builder_imgs/i15.png)
- For the Label, enter:
    ```
    Overdraft Limit
    ```
- Set **Required** to **On** and **Input Type** to **Decimal**

    ![Select Operations](./flow_builder_imgs/i16.png)

- **X** out of the form

- Hover over the arrow under the green block and above outputs, select the **Plus** button

![Select Operations](./flow_builder_imgs/i17.png)

- Select **Branch**

![Select Operations](./flow_builder_imgs/i18.png)

- Select the **Purple Diamond**

![Select Operations](./flow_builder_imgs/i19.png)

- Select the **code icon**

![Select Operations](./flow_builder_imgs/i20a.png)

- Enter the following condition:
    ```
    flow["User activity 1"]["Form 1"].output["Available Account Balance"] < flow["User activity 1"]["Form 1"].output["Overdraft Limit"]
    ```
![Select Operations](./flow_builder_imgs/i20b.png)

- Hover over the arrow labeled **Path 1**, is is located between the **Purple Diamond** and the outputs, click the **Plus** button

![Select Operations](./flow_builder_imgs/i21.png)

- Select **Generative Prompt**

![Select Operations](./flow_builder_imgs/i22.png)

- Change the **Model** to **llama-3-405b-instruct**

![Select Operations](./flow_builder_imgs/i23.png)

- Enter the following into **System Prompt**
    ```
    You are a financial planning assistant, create a financial plan based on the user's information.
    Include the fact that their avalible account balance is less than their overdraft limit. 
    Make a recommendation for an overdraft limit
    ```
- Enter the following into **User Prompt**
    ```
    Summarize the financial plan into bullet points, focus on open questions and suggestions
    ```
![Select Operations](./flow_builder_imgs/i24.png)

- Optionally, you may add an example

- Enter the following into **Input Prompt**
    ```
    Available Account Balance: $150.00
    Overdraft Limit: $200.00
    ```
- Enter the following into **Expected Output**
    ```
    - Your available balance is below your overdraft limit by $50.00, so focus on bringing your account back to a positive balance to avoid additional fees.

    - Review recent spending to identify nonessential expenses you can pause or reduce until your cash flow stabilizes.

    - Once your balance recovers, start setting aside a small emergency fund to Make a recommendation for an overdraft limit prevent future overdraft reliance.

    - Your available balance is below your overdraft limit by $50.00, so focus on bringing your account back to a positive balance to avoid additional fees.

    - Recommended limit: $50.00
    ```
![Select Operations](./flow_builder_imgs/i30.png)
![Select Operations](./flow_builder_imgs/i25.png)
- **X** out of this screen
![Select Operations](./flow_builder_imgs/i25.png)

- On **Path 2**, select the **Add +** button and select **Generative Prompt** again.

![Select Operations](./flow_builder_imgs/i26.png)

![Select Operations](./flow_builder_imgs/i27.png)


- Change the **Model Name** again to **llama-3-405b-instruct**

![Select Operations](./flow_builder_imgs/i28.png)

- Enter the following into **System Prompt**
    ```
    You are a financial planning assistant, create a financial plan based on the user's information and their healthy ratio between avalible balance and overdraft limit
    ```
- Enter the following into **User Prompt**
    ```
    Summarize the financial plan into bullet points, focus on open questions and suggestions
    ```
![Select Operations](./flow_builder_imgs/i29.png)

- Optionally, you may add an example

![Select Operations](./flow_builder_imgs/i30.png)

- Enter the following into **Input Prompt**
    ```
    Available Account Balance: $350.00
    Overdraft Limit: $50.00
    ```
- Enter the following into **Expected Output**
    ```
    - Your available balance is healthy relative to your overdraft limit, keeping you safely above potential fee territory.

    - You’re saving a reasonable portion of your income, though increasing contributions could accelerate progress toward your goals.

    - Building your emergency fund to cover 3–6 months of expenses will strengthen your overall financial stability.
    ```

- **X** out of this screen

![Select Operations](./flow_builder_imgs/i31.png)

- Click the **edit** button next to **Untitled** to add a title and description

 ![Select Operations](./flow_builder_imgs/i32.png)

- Enter the following into **Name**
    ```
    Financial Planner
    ```
- Enter the following into **Description**
    ```
    This tool helps users test a potential available account balance and overdraft limit to get financial planning advice. 
    This tool should be used when the user requests financial planning. 
    The available account balance and overdraft limit are hypothetical for the user, so they can use the advice to determine how they should set their account balance.
    ```
![Select Operations](./flow_builder_imgs/i33.png)

- Click **Save**

![Select Operations](./flow_builder_imgs/i33.png)

- Click **Done**

![Select Operations](./flow_builder_imgs/i32.png)

- In the **Agent Description**, add the following line:
     ```
    Use your financial planner tool if the user requests a financial planner
    ```
![Select Operations](./flow_builder_imgs/i34.png)

- To test, ask for a **financial planner** in the text box
