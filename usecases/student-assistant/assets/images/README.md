## Image Specifications

- **Format**: PNG (preferred) or JPG
- **Resolution**: Minimum 1200px width for clarity
- **Quality**: High quality, clear text
- **Annotations**: Add arrows, highlights, or callouts where helpful
- **Consistency**: Use consistent styling across all screenshots
- **Privacy**: Ensure no sensitive information is visible

## Capture Guidelines

1. **Clean Interface**: Close unnecessary tabs and windows
2. **Consistent Theme**: Use the same UI theme throughout
3. **Highlight Key Elements**: Use red boxes or arrows to highlight important UI elements
4. **Full Context**: Include enough surrounding UI for context
5. **Readable Text**: Ensure all text is legible at standard viewing size
6. **Consistent Zoom**: Use the same browser zoom level for all screenshots

## Tools for Screenshot Capture

- **macOS**: Command + Shift + 4 (selection), Command + Shift + 3 (full screen)
- **Windows**: Snipping Tool, Windows + Shift + S
- **Browser Extensions**: Awesome Screenshot, Nimbus Screenshot
- **Annotation Tools**: Skitch, Snagit, Preview (macOS)

## Organization

Images are referenced in markdown files using relative paths:
```markdown
![Description](assets/images/filename.png)
```

Ensure filenames match exactly with references in the markdown files.

## Maintenance

- Update screenshots when UI changes
- Review annually for accuracy
- Keep backup copies of all images
- Document any custom annotations or edits
- Version control images alongside markdown files
